黑猫语音助手 · 使用说明

1. 将整个压缩包解压到任意文件夹，双击 VoiceAssistant.exe。
   请保留旁边的 _internal 文件夹；不要直接在压缩包里运行。
   无需安装 Python，不需要管理员权限。

2. 在输入框输入“现在几点”并回车即可使用。
   语音就绪后，说“你好黑猫现在几点”或“黑猫打开记事本”。
   没有麦克风也能文字操作。连接麦克风后点击“重试麦克风”。
   输入框按 ↑↓ 可以找回最近发送的指令，返回下方会恢复未发送草稿。
   点“说一句”或在主窗口按 F8，可以不用唤醒词直接说话。
   设置 → 语音输入可选择麦克风，并开启连续对话。
   噪声环境建议说完整的“你好黑猫”，两字短词可能漏识别。

3. “暂停监听”可暂时关闭录音，文字输入仍可使用。
   按 Esc 或点“停止回答”停止生成与播报；之后可以继续提问。
   默认使用本地语音模型，首次加载需要一点时间，请查看窗口状态。

4. AI 聊天需要自行安装并启动 Ollama，再下载一个聊天模型。
   在“设置 → AI 对话”里刷新、选择模型。未安装 Ollama 不影响基本系统指令。
   联网语音及网页搜索需要网络；本地语音识别与合成无需网络。

5. 关闭窗口会隐藏到系统托盘，可从托盘重新打开或退出。
   重复双击程序会唤起已有窗口，不会重复占用麦克风。
   托盘不可用时，关闭窗口将直接退出。

6. 设置、对话记忆和日志默认位于：
   %LOCALAPPDATA%\KuronekoAssistant
   每个人在自己的电脑上独立保存，不会继承发送者的聊天记录。
   如需随 U 盘携带设置，可在 exe 旁创建空的 portable.flag 文件，
   之后数据会保存在同目录 userdata；再次分享前请移除 userdata。

7. 出现问题：托盘右键 → 运行诊断。
   分享给朋友时发送原始完整压缩包，不要单独发送 exe。

语音和音频设备效果取决于电脑硬件及 Windows 权限。
程序没有安装程序或自动上传聊天记录的功能。

新增指令示例：
五分钟后提醒我喝水 / 半小时后提醒我休息
查看提醒 / 取消最后一个提醒 / 取消第2号提醒 / 取消所有提醒
音量调到百分之五十 / 音量大一点 / 当前音量 / 静音 / 取消静音
下一首 / 上一首 / 播放暂停（需要播放器支持 Windows 媒体键）
最小化当前窗口 / 最大化当前窗口 / 还原当前窗口 / 关闭当前窗口
开启连续对话 / 结束对话 / 语音帮助 / 取消关机

提醒需要程序运行；关闭程序时不会唤醒电脑，到期提醒会在下次启动处理。
角色声音需单独配置本机 GPT-SoVITS 服务和参考音频，默认通用声音不等同角色声音。

声音不对或不出声时：
在设置 → 声音，点击“检测当前声音是否可用”。检测会实际合成，不播放、不回退；
“保存并试听当前声音”用于检查扬声器输出。微软在线返回 403 时，界面会显示原因，
并尝试本地自然语音，不能把回退声音当成微软在线声音。

GPT-SoVITS 是可选的外部本机服务。此包未包含该服务、角色模型或参考音频，
仅选择角色声音不会自动安装。请先运行 GPT-SoVITS 的 api_v2.py，准备参考音频和台词，
再在角色声音页填写并点击“检查角色服务与合成”。当前没有已验证的五更琉璃音色。

0.0.9 已适配微软在线语音的新合成地址。建议在设置 → 声音选择“微软在线语音”，
先检测，再保存并试听。仍需联网；服务端后续变化时会明确报错并尝试本地声音。
命令行主动合成诊断：VoiceAssistant.exe --debug --check-voice --no-file
